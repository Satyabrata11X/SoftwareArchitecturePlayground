About The Project

Architecture Studio

Architecture Studio is a modern System Design & Distributed Architecture Simulator developed using Spring Boot, Thymeleaf and PostgreSQL. It enables students and developers to visually design distributed systems, execute simulations, monitor live performance metrics, detect bottlenecks and generate professional reports.
